### 🛡️ About me

I'm a cybersecurity enthusiast who likes understanding how systems work all the way down, from the hardware on the desk to the packets on the wire to the APIs and models running on top. I enjoy finding weak spots, figuring out why they exist, and building things that are harder to break.

- 🔐 **Cybersecurity** is my main focus: securing systems, networks and applications
- 🔌 **APIs**: designing, building and testing them, with security in mind from the start
- 🤖 **Machine learning**: exploring how ML can help with things like threat and anomaly detection
- 🌐 **Network engineering**: routing, switching, segmentation and keeping traffic where it belongs
- 🖥️ **Hardware**: I build custom PCs for clients on the side, from picking parts to cable management to the first boot
